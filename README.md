# 세계지도 퍼즐 맞추기 대회 대진표

반별로 참가 번호(결번·불참 제외)를 입력하고 토너먼트 대진을 랜덤 추첨하는 페이지입니다.

바로 사용하기: https://cjsdls13-netizen.github.io/world-map-puzzle-bracket/

- 반 추가/이름 변경/삭제, 반별 설정·대진표·경기 결과 자동 저장(브라우저에 저장)
- 마지막 번호 입력 + 결번 클릭/입력
- 2의 거듭제곱이 아닌 인원은 부전승을 고르게 배치
- 번호를 눌러 승자 표시 → 다음 라운드로 자동 진출
- 화면 맞추기, 전체 화면, 인쇄(A4 가로)
